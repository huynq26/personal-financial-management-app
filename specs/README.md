# Feature specifications

The Product Agent writes versioned, reviewable feature specifications here, following `docs/templates/feature-spec.md`.

A spec is **Draft** until the product owner explicitly approves its scope and records that approval in GitHub. Each implementation issue must link to the exact spec, acceptance criteria and test plan. Codex Engineers implement approved issues; QC independently verifies them.

No MVP business feature is yet approved. The current application is a preview-only synthetic-data technical starter.
