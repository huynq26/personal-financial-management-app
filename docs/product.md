# Personal finance MVP — product proposal

**State: draft; requires Product Owner approval.** Follow the [Product Agent workflow](product-workflow.md). Feature specifications belong in `specs/` and must be linked from implementation issues after approval.

## Problem
People need a coherent view of income, expenses, assets and financial progress, without needing financial expertise.

## Initial audience
Individuals who want visibility into their financial position. Validate audience before implementation.

## Proposed smallest useful slice
Enter income/expense records manually and see monthly totals, balance and a simple savings trend. No real transactions, banking integrations, investment recommendations or credential storage until security and value requirements are approved.

## Important exclusions
No banking connection, crypto trading, personalized investment advice, or financial decision automation. Demo figures are entirely fictional.

## Functional acceptance criteria (to approve)
- User can enter and correct a record; invalid values are rejected.
- Monthly aggregation and savings calculation are correct.
- User receives clear feedback for error and empty states.
- Private user data cannot be accessed by another user.

## Evidence and metrics
Unvalidated hypotheses. Proposed metrics: journey completion, correctness, review time, user retention and feedback quality.

## Approval
Pending. Scaffold preview is not an approved feature or production release.
